# 📱 Mobile Sales Data Analysis Dashboard

An interactive **Mobile Sales Data Analysis Dashboard** built using **Microsoft Power BI** to analyze mobile phone sales, revenue, transactions, customers, brands, models, payment methods, and sales trends.

The dashboard transforms raw mobile sales data into meaningful business insights through interactive visualizations, KPIs, filters, and trend analysis.

---

## 📌 Project Overview

The **Mobile Sales Dashboard** is a Business Intelligence project designed to help understand mobile sales performance and customer purchasing patterns.

Using Power BI, the project provides an interactive way to analyze:

* Total sales
* Total quantity sold
* Total transactions
* Average selling price
* Sales trends over time
* Sales by mobile brand
* Sales by mobile model
* Sales by city
* Sales by payment method
* Customer purchasing behavior
* Customer ratings
* Day-wise and month-wise sales performance

The dashboard allows users to interact with different filters and explore the data from multiple perspectives.

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze overall mobile sales performance.

5. Identify commonly used payment methods.
6. Understand customer purchasing behavior.

## 📈 Dashboard Analysis

### 1. Sales Analysis

The dashboard provides an overview of total mobile sales and allows users to analyze how sales change across different periods.

This helps identify:

* High-performing periods
* Low-performing periods
* Sales trends
* Changes in customer demand

---

### 2. Brand Analysis

Mobile sales can be compared across different brands to determine which brands contribute the most to overall sales.

This analysis can help identify:

* Top-performing brands
* Brands with higher sales volume
* Differences in brand performance

---

### 3. Model Analysis

The dashboard allows individual mobile models to be compared based on their sales performance.

This helps identify popular products and models that contribute significantly to total sales.

---

### 4. City-Wise Analysis

Sales can be analyzed geographically using city-level information.

This helps answer questions such as:

* Which cities generate the highest sales?
* Where is demand concentrated?
* Which locations may require additional marketing?

---

### 5. Payment Method Analysis

The dashboard provides an overview of different payment methods used by customers.

Examples may include:

* Credit Card
* Debit Card
* UPI
* Cash
* Other digital payment methods

This helps understand customer payment preferences.

---

### 6. Customer Rating Analysis

Customer ratings can be analyzed to understand customer satisfaction and identify patterns between products and customer feedback.

---

### 7. Time-Based Analysis

The dashboard can be used to analyze sales across:

* Day
* Month
* Year
* Weekday
* Other available date dimensions

This helps identify seasonal and periodic sales patterns.
